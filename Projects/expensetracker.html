Expense Tracker

A simple web application designed to help users manage their daily expenses.

Project Overview

I created an Expense Tracker using HTML, CSS and JavaScript. It allows users to add expenses, view their spending and keep track of their daily budget.

Technologies Used

HTML, CSS and JavaScript

Key Features

  • Add new expenses
  • Enter expense names and amounts
  • Display a list of expenses
  • Calculate total expenses
  • Delete expenses from the list
  • Simple and user-friendly design

What I Learned

This project helped me understand JavaScript functions, event handling, DOM manipulation and basic calculations.
